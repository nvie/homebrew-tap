# homebrew-tap

Personal taps for Homebrew

```sh
brew tap nvie/tap
```

## Formulae

- `incredi-diff` — incremental code review in your terminal (macOS arm64 only)
- `git-toolbelt` — suite of useful Git commands
- `sr` — simple mass search & replace tool

Install any of them with `brew install nvie/tap/<formula>`.
